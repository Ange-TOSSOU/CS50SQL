# CS50 SQL

CS50 SQL is an introduction to Databases with SQL using SQLite, PostgreSQL and MySQL. It's a course delivered by the Harvard University which covered the topics below :

- Querying
- Relating
- Designing
- Writing
- Viewing
- Optimizing
- Scaling

Find more about this course on their [OpenCourseWare][cs50sql_material].

The course contains a bunch of problem sets. Some of them can be really challenging.
I created this repository to save all my solutions for those problems. Feel free to try its out, compare its to yours and give me your feedback if needed.
